# Icon provenance

The profile artwork embeds icon path data locally; it has no runtime CDN dependency.

## Simple Icons

The following marks were retrieved from
[`simple-icons/simple-icons`](https://github.com/simple-icons/simple-icons),
release `16.28.0` (`34c22501f9ac9f22b12f825677ccbab1fb22e14b`), on
2026-08-12. Simple Icons is distributed under CC0-1.0. Brand names and logos
remain the property of their respective owners. The paths are embedded in the
two responsive `profile-system*.svg` assets; no runtime CDN is used.

- `python.svg`
- `modelcontextprotocol.svg`
- `temporal.svg`
- `kubernetes.svg`
- `postgresql.svg`
- `grafana.svg`
- `githubactions.svg`

## Original generic line icons

The Java cup, cloud infrastructure, and model-integration symbols were drawn
specifically for this prototype. They are capability illustrations, not vendor
logos. Their adjacent text labels identify the technology being described.

- `java-generic.svg`
- `aws-generic.svg`
- `openai-generic.svg`

No Cisco marks or private-system identifiers are embedded in these assets.
